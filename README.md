# Celeor Agency — site statique

Site de Celeor Agency (marketplace de talents événementiels), construit par Pro Assistant IA.

- Hébergement : GitHub Pages (branche `main`, racine) — domaine `celeor-agency.com` (fichier `CNAME`).
- Aucune étape de build : les fichiers de ce dépôt sont servis tels quels.
- Pages : `index.html`, `catalogue.html`, `fiche.html`, `contact.html`, `appel-offres.html`, `parrainage.html`, `legal.html`.
- `data.js` : 7 catégories / 59 sous-catégories + prestataires ; `assistant.js` : assistant « Trouver mon prestataire ».
- Formulaires : envoi par formsubmit.co (adresse définie dans chaque page, `CELEOR_FORM_EMAIL`).

Sources et générateur (`build.py`) : dossier de travail Pro Assistant IA.
